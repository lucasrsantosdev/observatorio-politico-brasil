# Observatório Político Brasil

Projeto de engenharia de dados para extração, armazenamento e análise de dados públicos do Governo Federal.

## Objetivo

Construir uma plataforma com:

- Portal da Transparência
- Câmara dos Deputados
- Senado Federal
- PostgreSQL
- Python
- Power BI
- Rankings e indicadores políticos auditáveis

## Status

Projeto em construção.

| Ranking                                      | Fonte principal         |
| -------------------------------------------- | ----------------------- |
| Emendas, empenhado, liquidado e pago         | Portal da Transparência |
| Favorecidos e empresas recebedoras           | Portal da Transparência |
| Contratos e licitações federais              | Portal da Transparência |
| Gastos dos deputados, proposições e votações | Câmara dos Deputados    |
| Atividade legislativa e gastos dos senadores | Senado Federal          |
